KochiClassifieds Fun Page
===========================

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the ZIP.
2. Open index.html in any modern browser.

Behavior:
- The "Click me" button runs away forever on hover/click/tap.
- The Entebusiness.online link is a normal working link.
- The moving button avoids covering the Entebusiness.online link.

Note:
The KochiClassifieds button is intentionally a prank/runaway button, so it does not navigate away.
